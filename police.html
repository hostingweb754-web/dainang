Kebijakan Privasi

Terakhir diperbarui: 24 Juli 2026

📋 Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Parking Jam (selanjutnya disebut "Aplikasi", "Kami") yang dikembangkan oleh Strata Studio mengelola informasi pengguna. Kami menghargai dan berkomitmen melindungi privasi Anda.

Dengan mengunduh, menginstal, dan menggunakan Aplikasi ini, Anda menyetujui kebijakan privasi yang tertera pada halaman ini.

🔍 Informasi yang Dikumpulkan

Aplikasi Parking Jam adalah game puzzle offline yang tidak mengumpulkan data pribadi pengguna. Secara spesifik:

  • Kami tidak mengumpulkan nama, alamat email, nomor telepon, atau informasi identitas pribadi lainnya.
  • Kami tidak mengumpulkan data lokasi (GPS) pengguna.
  • Kami tidak mengumpulkan foto, video, atau file dari perangkat Anda.
  • Kami tidak mengumpulkan riwayat penelusuran atau aktivitas online Anda.

📌 Catatan Penting: Semua data progres permainan (level, koin, pengaturan suara, dan skin mobil) disimpan secara lokal di perangkat Anda menggunakan penyimpanan internal aplikasi dan tidak pernah dikirim ke server manapun.

✅ Tidak Ada Pengumpulan Data Pribadi

🔐 Izin Aplikasi

Aplikasi ini memerlukan izin minimum untuk berjalan:

  • Akses Internet (opsional): Digunakan hanya untuk memuat font Google Fonts saat pertama kali dijalankan. Tidak ada data pengguna yang dikirimkan.
  • Penyimpanan Internal: Digunakan untuk menyimpan progres permainan secara lokal di perangkat Anda.

Aplikasi ini tidak memerlukan akses kamera, mikrofon, kontak, lokasi, atau izin sensitif lainnya.

🌐 Layanan Pihak Ketiga

Aplikasi Parking Jam saat ini tidak menggunakan layanan analitik, pelacakan (tracking), atau jaringan iklan pihak ketiga seperti Google Analytics, Firebase Analytics, Facebook SDK, atau platform serupa.

Jika di masa mendatang kami mengintegrasikan layanan pihak ketiga, kebijakan privasi ini akan diperbarui terlebih dahulu untuk memberitahu Anda.

🛡️ Keamanan Data

Karena kami tidak mengumpulkan atau mengirimkan data pribadi apapun, risiko kebocoran data dari Aplikasi ini sangat minimal. Seluruh data game tersimpan hanya di penyimpanan lokal perangkat Anda dan sepenuhnya berada di bawah kendali Anda.

Menghapus instalasi (uninstall) Aplikasi akan menghapus seluruh data permainan yang tersimpan di perangkat Anda secara permanen.

👶 Privasi Anak-Anak

Aplikasi Parking Jam aman digunakan oleh semua kalangan usia, termasuk anak-anak di bawah 13 tahun. Kami tidak mengumpulkan informasi pribadi dari siapapun, termasuk anak-anak.

Aplikasi ini tidak mengandung konten kekerasan, perjudian, atau materi tidak pantas lainnya. Game ini dikategorikan sebagai Semua Umur (PEGI 3 / Everyone).

📝 Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Setiap perubahan akan dipublikasikan pada halaman ini dengan tanggal pembaruan terbaru. Kami menyarankan Anda untuk meninjau halaman ini secara berkala untuk mengetahui perubahan terbaru.

Perubahan pada kebijakan ini berlaku efektif segera setelah dipublikasikan di halaman ini.
